# Data Files

本目录只包含聚合统计，不包含原始论文、完整章节、逐篇正文或可还原原文的数据。

## 文件说明

- `corpus-overview.csv`：按年份统计文件数、语言质量类别和词元数。
- `domain-summary.csv`：研究问题、方法谱系、贡献类型的规则式候选标签统计。
- `section-patterns.csv`：章节类别覆盖、词元规模和常见前后关系。
- `section-sequences.csv`：常见章节功能序列。
- `section-heading-frequency.csv`：常见章节标题。
- `section-coverage-by-era.csv`：章节覆盖随时期变化。
- `abstract-stats-by-era.csv`：摘要长度和句数统计。
- `section-lexicon.csv`：分章节内容词频率、文档覆盖和年代范围。
- `collocations.csv`：分章节 2–5 元搭配候选。
- `terminology-frequency.csv`：人工定义 EC 术语的分章节统计。
- `rhetorical-phrases.csv`：常见修辞短语的分章节统计。
- `abstract-rhetorical-moves.csv`：摘要修辞动作的 cue-based 统计。
- `abstract-move-sequences.csv`：摘要修辞动作序列候选。
- `introduction-paragraph-moves.csv`：引言段落功能的 cue-based 统计。
- `title-patterns.csv`：标题结构模式统计。
- `sample-summary.csv`：150 篇定性复核样本的分层覆盖汇总。

## 解释原则

- 频次必须结合文档覆盖、时期和章节解释。
- `other` 类章节包含大量领域特定小节，不能与标准章节直接比较。
- cue-based 修辞分类用于定位复核，不是精确话语标注。
- 2020–2023 的现象不单独定义历史稳定规则。
