# 限制与偏倚

## 1. 单期刊边界

证据全部来自 TEVC。它可以反映该期刊和 EC 研究共同体的重要写作实践，但不能覆盖所有会议、期刊和应用领域的规范。

## 2. OCR/转换质量

Markdown 由版式复杂的 PDF 转换而来，存在：

- 双栏串字；
- 公式丢失；
- 页眉、单位、作者简介混入；
- 表格和算法块误识别；
- 个别标题提取或章节分类错误。

脚本使用质量分数排除高噪声语言样本，但不能保证每句解析都正确。公开统计应被视为写作研究的辅助证据，而非对论文原文的完美数字化。

## 3. 自动分类边界

领域标签来自标题、摘要和关键词的规则匹配：

- 503 篇方法谱系未标注；
- 260 篇问题环境未标注；
- 17 篇贡献类型未标注。

这些标签是候选路由，不是人工金标准。Skill 中只有证据充足的方向建立深入规则。

## 4. 精选样本边界

150 篇样本按时期、贡献类型和问题环境分层，但不能消除：

- 主编和审稿规范变化；
- 作者群体变化；
- 主题流行度变化；
- 高影响力论文与普通论文的语言差异；
- 人工判断的主观性。

## 5. 年代边界

1997–2019 用于识别跨时期稳定实践；2020–2023 用于纳入近期范式。由于用户担心后期语料可能受到 LLM 润色影响，所有 2020 后才明显的现象都标注为近期实践，不用于单独定义核心规则。

## 6. 使用限制

Skill 不承诺论文被录用，不替代领域研究设计，也不应把统计高频作为审稿规定。它能帮助识别结构、证据和语言风险，但最终学术判断必须由作者完成。
