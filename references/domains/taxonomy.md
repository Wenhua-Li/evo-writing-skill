# EC 领域三维分类与路由

不要把 EC 写成一张算法名单。写作时同时使用三个维度。

## 1. 研究问题/环境

- **连续/实参数优化**：强调搜索空间、变量尺度、局部最优、收敛精度。
- **离散/组合优化**：编码、可行性、修复、邻域结构、问题专用算子。
- **多目标/高目标**：收敛、多样性、目标数、偏好、指标和可视化。
- **约束优化**：可行性、约束违反、约束—目标权衡、约束处理成本。
- **动态/非平稳**：变化检测、响应速度、跟踪、预测和记忆。
- **噪声/不确定/鲁棒**：评价误差、重采样、置信度、最坏情况或分布性能。
- **昂贵/代理辅助**：真实评价预算、模型误差、模型管理、模型训练开销。
- **大规模**：维度、变量交互、分解、降维、资源分配和可扩展性。
- **多峰**：多个局部/全局解、niching、决策空间多样性。
- **多任务/迁移**：任务相似性、知识表示、正/负迁移和迁移成本。
- **双层/分层**：上下层耦合、响应映射、计算成本和可行性。
- **机器学习任务**：泛化、数据划分、类别不平衡、解释性和过拟合。
- **真实应用**：领域约束、数据、基线、部署成本和实际价值。

## 2. 方法谱系

- GA / ES / EP
- DE
- GP / grammatical evolution
- PSO / ACO / swarm intelligence
- EDA / model-based search
- memetic / local-search hybrids
- coevolution / multipopulation
- learning classifier systems
- artificial immune systems
- neuroevolution / evolutionary ML
- ML-assisted / surrogate-assisted hybrids
- hyper-heuristics / automatic algorithm design

方法谱系决定术语和实现细节，但不能替代问题环境。例如 DE 可用于连续单目标，也可改造用于组合、多目标、约束或昂贵问题，写作逻辑必须随问题变化。

## 3. 贡献类型

- 新算法/改进算法
- 表示或算子
- 参数控制/自适应
- 理论分析
- benchmark/test suite
- 指标/评价协议
- 综述
- 软件/框架
- 应用

## 4. 路由示例

- “DE + 昂贵多目标 + 新算法”：使用多目标的收敛/多样性逻辑 + 昂贵问题的预算和模型管理逻辑 + 算法论文证据链。
- “GP + 动态调度 + 应用”：使用 GP 的表示/解释性逻辑 + 动态环境的响应逻辑 + 应用论文的领域验证逻辑。
- “runtime analysis + 约束 + 理论”：使用理论论文的假设/界限逻辑 + 约束问题的可行性逻辑。
- “survey + surrogate-assisted EMO”：使用综述的分类和证据综合逻辑 + 昂贵优化的模型管理分类轴。

## 5. 语料覆盖的提醒

自动标签显示多目标、真实应用、机器学习任务、组合/约束和大规模研究覆盖较多；部分方法谱系如 EP、LCS 和 artificial immune systems 在后期样本较少。规则撰写时必须区分：

- 跨时期稳定实践；
- 某领域特定实践；
- 近期才兴起、证据主要来自 2020–2023 的实践；
- 仅由少数论文支持的观察。
