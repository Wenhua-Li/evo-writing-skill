Install EvoWrite

Choose the installation path that matches your agent. The installed directory is named evo-write.

Skills CLI

npx skills add Wenhua-Li/evo-writing-skill

Bash

curl -fsSL https://raw.githubusercontent.com/Wenhua-Li/evo-writing-skill/main/install.sh | bash

Useful options: --agent claude, --agent codex, --agent kimi, --ref v0.4.0, --force, --doctor.

Windows PowerShell

iwr https://raw.githubusercontent.com/Wenhua-Li/evo-writing-skill/main/install.ps1 | iex
