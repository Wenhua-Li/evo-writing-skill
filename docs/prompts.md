# Prompt recipes

## Rewrite an abstract

```text
Use evo-write. Rewrite this abstract to sound like a careful EC researcher wrote it.
Remove AI tells, boilerplate, and defensive framing. Preserve every number, citation, and scope condition.
Return only the revised English.
```

## Humanize an introduction

```text
Use evo-write. Humanize this introduction for a TEVC-style algorithm paper.
Do not add citations or results. Reduce template-like contribution lists unless they are genuinely needed.
```

## Fix claim strength

```text
Use evo-write. Rewrite this results paragraph so the claims match the evidence.
Do not use statistically significant unless a test is provided. Do not use optimal unless a formal guarantee is provided.
```

## Expensive multiobjective paper

```text
Use evo-write. Rewrite this experimental setup for a surrogate-assisted multiobjective EA.
Check that exact evaluations, surrogate training cost, runtime, and model-management choices are not conflated.
```

## Large-scale MOEA

```text
Use evo-write. Rewrite this introduction for a large-scale multiobjective DE paper.
Focus on variable interaction, evaluation budget, and grouping cost rather than generic dimensionality claims.
```

## Voice matching

```text
Use evo-write. This is a sample of my English writing:
[sample]

Match its sentence rhythm, transitions, and level of directness. Rewrite this section:
[target]
```

## Audit before submission

```text
Use evo-write in Audit mode. Review this full manuscript section by section.
Prioritize: claim–evidence alignment, EC terminology, cost measures, statistical support, defensive writing, and AI tells.
```

## Chinese notes to English draft

```text
Use evo-write. Draft the method overview in English from these Chinese notes.
Do not invent mechanism details, citations, baselines, or numerical outcomes. List missing details after the draft, not inside the paper text.
```
