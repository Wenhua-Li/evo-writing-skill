# 语料研究方法与边界

## 1. 语料

- 来源：本项目本地的 TEVC Markdown 转换文本。
- 主分析范围：1997–2023 年正式年份目录。
- 文件数：1,517。
- 摘要识别：1,516 篇。
- 明确 Introduction：1,355 篇。
- 明确 Conclusion：1,219 篇。
- 语言统计使用：1,358 篇。
- 高 OCR/公式噪声待复核：100 篇。
- 仅元数据使用：59 篇。
- 正文语言词元：约 1,127 万。

2024 年及以后目录、early access 目录未进入任何统计、规则、例句或反例。

## 2. 清洗

脚本执行以下处理：

- 识别标题、摘要、Index Terms、章节和小节；
- 将正文映射到 introduction、related work、preliminaries、method、theory、experiments、results、discussion、conclusion 等类别；
- 从语言统计中移除参考文献、作者简介、页眉页脚、DOI/单位、图表标题和 `picture text` 公式碎片；
- 记录 OCR 替换字符、异常长词和高 Unicode 字符，按词元归一化形成质量分数；
- 保留逐篇质量原因，不静默排除。

## 3. 定量分析

- 年度/质量/词元统计；
- 章节覆盖、标题和顺序统计；
- 分章节词元、2–5 元搭配、术语和修辞短语统计；
- 三维候选标签：研究问题、方法谱系、贡献类型；
- 摘要和引言的 cue-based 修辞动作统计。

修辞动作分类是透明启发式，用于定位人工复核，不声称为精确话语标注。

## 4. 分层精读

采用确定性分层抽样：

- 时期：1997–2004、2005–2012、2013–2019、2020–2023；
- 每个时期约 37–38 篇，共 150 篇；
- 强制覆盖新算法、应用、理论、综述、benchmark/指标、表示/算子、参数控制；
- 在研究问题维度上尽量覆盖多目标、约束、动态、不确定、昂贵、大规模、多峰、组合、机器学习任务等；
- 对摘要、Introduction、Method、Experiments/Results、Conclusion 做重点阅读，核心范式论文阅读更多上下文。

这表示“全语料自动分析 + 150 篇分层重点阅读”，不声称人工逐字精读全部 1,517 篇。

## 5. 证据等级

- **A：跨时期语料稳定 + 人工样本确认**。可作为通用规则，但仍要看论文类型。
- **B：特定领域/论文类型中稳定**。只在该上下文推荐。
- **C：编辑性规则或理论论证需要**。不一定由词频直接支持，但符合学术论证和术语准确性。
- **近期实践**：主要证据来自 2020–2023，明确标注，不包装成创刊以来传统。

## 6. 反污染策略

不做不可靠的“AI 文本检测”。采用：

1. 硬性年代边界；
2. 1997–2019 对照；
3. 跨时期出现与文档覆盖率检查；
4. 人工样本复核；
5. 将近期专属现象标注为近期实践。
