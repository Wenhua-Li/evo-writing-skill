# Voice Profile: Application Paper

适用于真实应用、工程优化、数据驱动优化和领域决策支持。

## 声音特征

- 先写真实任务和约束，再写优化模型。
- 术语必须能被领域读者和 EC 读者同时理解。
- 结果强调实际意义，同时保留算法评价口径。
- 不把单个案例写成行业普遍结论。

## 节奏

- 应用背景具体但不冗长。
- 建模段落清楚、平稳。
- 实验结果连接领域指标和优化指标。

## 偏好表达

- `The objective is to ...`
- `The evaluation uses incident records from ...`
- `Compared with the current planning rule, ...`
- `The resulting configurations reduce ...`

## 避免

- 宏大行业宣传；
- 没有领域基线；
- 只报告 benchmark 分数；
- 把 demonstration 写成 deployment。
