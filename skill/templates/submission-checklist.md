# Submission Checklist

## 1. 贡献与结构

- [ ] 标题能看出研究对象和核心贡献。
- [ ] 摘要中的每个结果都在正文有证据。
- [ ] Introduction 的缺口能映射到方法机制。
- [ ] 贡献列表没有同义重复。
- [ ] Related Work 按设计原则比较，不是逐篇罗列。
- [ ] 结论包含证据范围和限制。

## 2. 方法与可复现性

- [ ] 问题、变量、目标、约束定义完整。
- [ ] 表示、初始化、变异、选择、归档/模型管理清楚。
- [ ] 伪代码有输入、输出、初始化和终止条件。
- [ ] 参数作用、来源和敏感性清楚。
- [ ] 复杂度、FEs、运行时间和模型开销没有混淆。
- [ ] 与直接前驱的差异明确。

## 3. 实验与统计

- [ ] Benchmark/instance 覆盖论文声称的问题困难。
- [ ] 基线包含直接前驱和强相关方法。
- [ ] 比较预算公平。
- [ ] 指标方向、参考点、归一化明确。
- [ ] 独立运行和统计检验清楚。
- [ ] 消融对应核心机制。
- [ ] 报告失败或例外场景。
- [ ] 多目标论文区分 convergence、diversity 和 feasibility。
- [ ] 昂贵优化报告真实评价预算和模型开销。
- [ ] 动态问题报告变化模型和跟踪表现。

## 4. 语言与断言

- [ ] `significant` 有统计依据。
- [ ] `optimal` 有定义和保证。
- [ ] `robust` 指明扰动。
- [ ] `scalable` 指明维度和范围。
- [ ] `efficient` 指明成本口径。
- [ ] `state-of-the-art` 有具体基线。
- [ ] 没有无证据的 `always`、`best`、`universal`。
- [ ] 缩写、符号和指标方向一致。

## 5. 图表与补充材料

- [ ] 所有图表在正文中被引用并解释。
- [ ] 图题/表题自包含。
- [ ] 补充材料不承载正文唯一关键证据。
- [ ] 代码、数据和参数可获得性说明与实际情况一致。
